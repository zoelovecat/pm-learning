# pm-learning

Giáo trình tự học PM (35 bài, 10 chương) từ quy trình PM. Có theo dõi tiến độ, checkpoint sau mỗi bài và file ôn tự sinh.

## Mỗi buổi học

1. Claude đọc `progress.md`, xác nhận bài hôm nay.
2. Dạy bài (10-15 phút).
3. Checkpoint 4 câu: 2 lý thuyết + 2 tình huống, hỏi từng câu.
4. Lưu tiến độ: từ 3/4 là `xong`, dưới 3/4 là `xong (cần ôn)`.
5. Sinh `interview/<Mã>-<slug>.md` để ôn phỏng vấn.
6. Hỏi có sang bài tiếp theo không.

Lệnh khác: `mình học tới đâu`, `ôn tập`, `QS-TST-04 là gì`, `đánh dấu Ch2·01 xong`.

## Tệp

| Tệp | Là gì |
|---|---|
| `ROADMAP.md` | Lộ trình 35 bài |
| `chapters/` | Nội dung bài (`Ch4·04` = chương 4, bài 04) |
| `progress.md` | Tiến độ |
| `interview/` | File ôn phỏng vấn |
| `cheatsheet.md`, `glossary.md` | Tra nhanh công thức, thuật ngữ |
| `SKILL.md`, `CLAUDE.md` | Chỉ dẫn cho Claude |

Không có Claude vẫn học được: đọc `ROADMAP.md` và `chapters/`, tự cập nhật `progress.md`.

Chỗ nguồn tự mâu thuẫn được ghi `(nguồn chưa rõ)`, tổng hợp ở mục 9 của `cheatsheet.md`.
